                           PROCESSING TIMELINE

Query Received
    │
    ├─► Parse request (5ms)
    │
    ├─► Execute models in parallel (30-120s per model)
    │
    ├─► Market research extraction (100ms all models)
    │
    ├─► Thesis extraction & dedup (150ms all models)
    │
    ├─► Consensus detection (20ms)
    │
    ├─► Contradiction analysis (20ms)
    │
    ├─► Investment scoring (1ms)
    │
    ├─► Database persist (10ms)
    │
    └─► Respond with results


                        KEY DESIGN PRINCIPLES

1. MODULARITY
   ├─ Each agent independent
   ├─ No inter-agent dependencies
   └─ Easy to test and extend

2. DETERMINISM
   ├─ No randomization
   ├─ Same input → same output
   ├─ Reproducible analysis
   └─ MD5-based consistent IDs

3. CONSENSUS-FOCUSED
   ├─ Multi-model agreement emphasized
   ├─ Contradictions highlighted
   ├─ No fake consensus
   └─ Confidence reflects breadth

4. EXTENSIBILITY
   ├─ New agents easy to add
   ├─ Pluggable configuration
   ├─ Custom focus areas
   └─ Scoring formula tunable

5. INTEGRATION
   ├─ Reuses OrchestrationPipeline
   ├─ Existing provider infrastructure
   ├─ Standard event streaming
   └─ Database persistence via existing models
